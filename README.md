# 🧱 Stack Simulation Project

A simple console-based Stack Simulation implemented in C, demonstrating fundamental Data Structures operations such as Push, Pop, Peek, and Display. This project helps visualize stack behavior with overflow and underflow handling.

---

## 🚀 Features
- Array-based stack implementation  
- User-defined maximum stack size  
- Push operation  
- Pop operation  
- Peek (Top element)  
- Display stack contents  
- Overflow & Underflow detection  
- Clean menu-driven interface

## 🎮 Operations Explained

### ▶ Push  
Adds an element to the top of the stack.  
Shows **Stack Overflow** if full.

### ▶ Pop  
Removes the top element.  
Shows **Stack Underflow** if empty.

### ▶ Peek  
Displays the current top element.

### ▶ Display  
Prints all stack elements from **top to bottom**.
